# Lyr for Windows — installer downloads

This repository hosts the Windows installer and update files for [Lyr](https://lyr.app). The application source is private; this repo exists so the installer and the in-app updater can download without a GitHub account.

## Download

Get Lyr for Windows from **[lyr.app/downloads](https://lyr.app/downloads/)**, which always points at the newest release here.

The installer is a standard NSIS setup for Windows 10/11 (x64). Installed copies update themselves from the releases in this repository.

## System requirements

- Windows 10 (64-bit) or newer
- ~500 MB free disk space

## Feedback

Use **Report a problem** in Lyr's Settings.
